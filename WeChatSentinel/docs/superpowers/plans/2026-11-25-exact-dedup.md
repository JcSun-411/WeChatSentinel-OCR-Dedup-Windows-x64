# 实时微信正文完全重复去重

**目标：** 用户已选择所有实时监控群统一去重。OCR/UIA 采集中，完整入库正文相同时只保留首次记录，不受群聊、发送者、时间、消息 ID 或程序重启影响。

**实现：** 独立外键表保存实时消息正文 SHA-256，按索引查候选后比较完整正文，避免哈希碰撞误判。迁移 `0005` 分批补旧记录的指纹，保留旧消息。新增消息与指纹在同一事务中写入。删除、过期清理和清空时级联清理，允许之后重新收录。

**边界：** 使用现有入库清理后的正文逐字相等，不用相似度，不进一步忽略内部空格、标点、数字。既有 OCR 缩放重排身份复用保留。仅作用于实时微信 OCR/UIA，Mock 和历史导入保留原规则；不保存未命中正文。已有重复记录不自动删除。

## 重点检查

- 跨群去重不触碰未授权来源，跨 OCR/UIA 也只收一次。
- 查询使用指纹索引，仍逐字比较正文；指纹不含来源元数据。
- 只为实际保存的消息留指纹，不妨碍后来命中的消息收录。
- 事务失败不留下指纹和统计；历史清空不遗留不可解释的去重状态。
- 首次记录的归属群和时间保留，重复消息不重复通知或分类。
